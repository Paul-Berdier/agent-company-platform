# Implémentation progressive

Adaptation ACP de addyosmani/agent-skills, commit a06bc63b3f8b829c14b0bbf53d99fefc39d58092 (MIT). Texte intégral et références conservés dans le catalogue ; cette application est une synthèse française ciblée, pas la totalité du texte amont.

Avancez par modifications petites et complètes : lire le code concerné, modifier une tranche cohérente, vérifier son comportement puis examiner le diff. Réutilisez les conventions et composants existants. Gardez les validations, migrations et appelants cohérents avec le changement. Une erreur doit être comprise avant de poursuivre ; évitez les corrections spéculatives accumulées.
