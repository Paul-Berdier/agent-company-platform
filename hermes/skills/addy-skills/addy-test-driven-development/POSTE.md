# Tests qui prouvent le comportement

Adaptation ACP de addyosmani/agent-skills, commit a06bc63b3f8b829c14b0bbf53d99fefc39d58092 (MIT). Texte intégral et références conservés dans le catalogue ; cette application est une synthèse française ciblée, pas la totalité du texte amont.

Pour une logique non triviale ou une régression, écrivez un test du comportement attendu et constatez son échec pertinent avant la correction, puis son succès après. Évitez les tests qui recopient l’implémentation. Choisissez les outils déjà utilisés par le dépôt (Qt Test, pytest, etc.) ; les exemples JavaScript amont ne prescrivent aucune dépendance. Distinguez les tests lancés, leurs résultats, les tests ignorés et les limites.
