# Interface, clavier et accessibilité

Adaptation ACP de addyosmani/agent-skills, commit a06bc63b3f8b829c14b0bbf53d99fefc39d58092 (MIT). Texte intégral et références conservés dans le catalogue ; cette application est une synthèse française ciblée, pas la totalité du texte amont.

Commencez par les parcours et les états réel, vide, chargement et erreur. Réutilisez les composants et jetons du produit ; adaptez les exemples web au framework réellement utilisé, notamment Qt/QML. Vérifiez dimensions réduites, texte long, contraste, navigation clavier, focus visible et noms accessibles. Une capture ou un test automatise une preuve précise, jamais une conformité globale inventée. Ne remplacez pas les données manquantes par un état de succès.
