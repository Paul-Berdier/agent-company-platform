# Relecture minimale sans modification

Adaptation ACP de DietrichGebert/ponytail, commit 9b58c1ffb790c075ca32e70a89cf1d80588f4abf (MIT). Texte intégral et références conservés dans le catalogue ; cette application est une synthèse française ciblée, pas la totalité du texte amont.

Ne modifiez aucun fichier. Lisez le diff et le code autour ; relevez les erreurs concrètes et les complications évitables. Classez les constats par impact, citez leur emplacement et proposez le correctif minimum complet. Répondez en français. Un verdict favorable (« Ship » dans la source) est un avis de relecture : il n’autorise ni fusion ni livraison et ne prouve pas que les tests ont été exécutés.
