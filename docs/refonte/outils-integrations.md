# Outils et compétences — préparation 1.2.0

La page native **Outils** lit le catalogue du Hermes auquel la session est connectée. La recherche porte sur les noms, descriptions, profils et états ; les filtres séparent skills, MCP et sources étudiées. Une erreur conserve la dernière lecture datée. La déconnexion ou le changement de serveur l’efface.

Une skill « Texte chargé » est trouvée par le chargeur de Hermes. Ce statut ne confirme ni l’installation d’un logiciel tiers, ni un compte fournisseur, ni l’utilisation du texte dans une tâche donnée. Un serveur MCP n’est dit connecté que lorsque le catalogue publie sa connexion. Le registre embarqué des dix sources ne sonde aucun service externe.

**Préparer une consigne** ajoute un texte au brouillon de Discussion, sans l’envoyer. Le brouillon existant est conservé. La Discussion reste globale : cette action ne rattache pas une conversation à un projet. Le choix du profil au lancement d’un projet détermine les adaptations textuelles associées aux classes de tâches ; leur présence dans un profil n’est pas une preuve d’exécution. Les permissions, fournisseurs et quotas restent régis par ACP.

**Copier la fiche** copie une préparation lisible : endpoint réel, transport, prérequis et champs encore à fournir. Aucun installateur ou fichier de configuration actif n’est produit. Les clés restent dans le coffre du service ; elles ne doivent pas être collées dans Discussion. L’ajout d’un serveur distant exige son admission explicite dans le catalogue et la garde de Hermes, avec des outils nommés. Ce lot ne modifie pas cette garde.

Le registre versionné est [sources.json](../../apps/desktop/resources/integrations/sources.json). Il contient les commits complets, liens de licence, prérequis et fiches copiables. Les textes de projets externes sont des sources consultées, pas des instructions ayant autorité sur ACP. Le rôle de chef de projet est une adaptation ACP ; aucun dépôt externe non identifié ne lui est attribué.

Les nouveaux tests natifs utilisent un faux Hermes : lecture authentifiée, pause hors page/session, réponse tardive oubliée, état MCP distinct d’un texte, recherche et gestes locaux sans installation. Les résultats d’exécution et la validation visuelle seront consignés dans la preuve de livraison après leur acquisition. Aucun compte ou service externe personnel n’a été connecté pour préparer ce lot.
