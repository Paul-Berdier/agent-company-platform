# Captures de validation

Les images de ce dossier proviennent du navigateur ou du client Qt réels.
Elles documentent un état vérifié à une date donnée ; elles ne remplacent
ni les tests automatisés ni un scénario E2E.

- `lot-a-home-dark.png` : accueil du shell moderne, thème sombre, viewport demandé
  1440 × 1000 (capture de contenu 1425 × 990), API locale alimentée par une base de
  démonstration isolée, 11 septembre 2026.
- `lot-a-missions-mobile-light.png` : formulaire Missions réellement rendu, thème
  clair, viewport demandé 390 × 844 (capture de contenu 375 × 812), même API locale.
- `desktop-command-palette-dark.png` : shell Qt 1280 × 800 et palette sombre,
  saisie clavier « Projets », 23 septembre 2026. Capture `grabWindow()` du test natif
  `tst_desktop_interactions`, données synthétiques isolées.
- `desktop-projects-light.png` : écran Projets Qt en thème clair, fenêtre 960 × 700,
  même harnais et même date. Aucun compte personnel ni fournisseur payant utilisé.
